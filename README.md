# 📋 Complaint Hub System

A Full-Stack web application built using the MERN stack that allows users to file complaints and enables administrators to view and manage them in real time. 

---

## ✨ Core Features

* **User Portal:** Users can easily submit detailed complaints across different categories (such as Campus Utilities or Corporate Workspace setups).
* **Admin Dashboard:** A secure dashboard built exclusively for administrators to track, review, and manage incoming grievances.
* **Secure Database:** Powered by MongoDB Atlas cloud storage to ensure all user records and complaints are saved safely in real time.
* **Privacy Protected:** Built using hidden configuration files so that database passwords and private keys are never exposed publicly.

---

## 🛠️ Technology Stack

* **Frontend (User Interface):** React.js, Tailwind CSS, Vite.js
* **Backend (Server):** Node.js, Express.js
* **Database:** MongoDB Atlas (Cloud Cluster)
* **Security:** JSON Web Tokens (JWT) for secure user login sessions
